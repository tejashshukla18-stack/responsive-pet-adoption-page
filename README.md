# 🐾 Pawfect Match - Pet Adoption Page

A clean, responsive static website created to help connect shelter dogs and cats with prospective adoptive families. 

---

## 🌟 Features
- **Browse Pets:** High-quality photos and details for shelter dogs and cats.
- **Responsive Layout:** Built with CSS for smooth viewing across desktop and mobile devices.
- **Adoption Info:** Clear sections guiding users on how to start the adoption process.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic structure and content.
- **CSS3:** Custom layout, styling, and responsiveness.
